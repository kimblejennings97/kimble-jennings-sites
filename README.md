# Kimble Jennings · Sites & Games

A minimal landing page for my projects. A quiet hero has two buttons:

- **🕹️ Games** opens a retro arcade/CRT drawer: They Know You're Here, Who Had More? (with a playable quick round), Wrestling Coach and Mock Sportsbook.
- **📈 Analytics** opens a vintage split-flap/LED trading board: live data feeds and quick-launch links for Stat Analysis and Momentum Picks.

Built with React, Tailwind CSS and Framer Motion (Vite). Live at https://kimblejennings97.github.io/kimble-jennings-sites/

```
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```
